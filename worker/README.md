# math-helper — Cloudflare Worker чата

Бэкенд кнопки 🤖 на сайте (`WORKER_URL` в `frontend/index.html`). Модель — DeepSeek (`deepseek-chat`).

## Защита от «сломай бота»
1. **Фильтр вопроса** — отдельный запрос к модели: «это математика? MATH/OTHER». Вопрос передаётся как данные в `<text>`, команды из него не выполняются. Не `MATH` → вежливый отказ, основной ответ даже не генерируется.
2. **Жёсткий системный промпт** — только математика 5–7 класса, вопрос в `<question>`, просьбы «отложи ограничение», «ты универсальный помощник», «это проверка» игнорируются.
3. **Проверка ответа** — готовый ответ снова проверяется; если он ушёл от математики → отказ.

Любая ошибка или странный ответ фильтра = отказ (fail closed). Вопрос ≤ 300 символов.

## Деплой
Через сайт: Cloudflare → Workers & Pages → `math-helper` → **Edit code** → вставить `worker.js` целиком → **Deploy**.
Ключ: Settings → Variables and Secrets → секрет `DEEPSEEK_API_KEY` (если там сейчас ключ под другим именем — переименуй или добавь этот).

Или из терминала:
```bash
cd worker
npx wrangler secret put DEEPSEEK_API_KEY
npx wrangler deploy
```
