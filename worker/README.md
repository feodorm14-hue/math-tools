# math-helper — Cloudflare Worker чата

Бэкенд кнопки 🤖 на сайте (`WORKER_URL` в `frontend/index.html`).
Ищет похожие задачи в базе (Vectorize `math-helper`, эмбеддинги `bge-small-en-v1.5` через Workers AI)
и отвечает через DeepSeek (`deepseek-chat`). Ссылки `[1] [2]` — `url` двух ближайших задач.

- `worker.js` — актуальная версия с защитой.
- `original.js` — резервная копия того, что было в Cloudflare до защиты.

## Защита от «сломай бота»
1. **Фильтр вопроса** — отдельный запрос к модели: «это математика? MATH/OTHER». Вопрос передаётся как данные в `<text>`. Не `MATH` → вежливый отказ, база и основной ответ даже не трогаются.
2. **Жёсткий системный промпт** — только математика 5–7 класса; вопрос в `<question>`, материалы базы в `<materials>`, просьбы «отложи ограничение», «ты универсальный помощник», «это проверка» игнорируются.
3. **Проверка ответа** — если ответ ушёл от математики → отказ.
4. **Загрузка в базу** (`X-Action: upload`) — только с заголовком `X-Upload-Token`, равным секрету `UPLOAD_TOKEN`. Без секрета загрузка выключена.

Любая ошибка или странный ответ фильтра = отказ. Вопрос ≤ 300 символов.

## Деплой
Cloudflare → Workers & Pages → `math-helper` → **Edit code** → заменить весь код на `worker.js` → **Deploy**.
Секрет `DEEPSEEK_KEY` и привязки `AI`, `VECTORIZE` уже есть — трогать не нужно.
Чтобы снова загружать задачи: Settings → Variables and Secrets → добавить секрет `UPLOAD_TOKEN` и слать его в заголовке `X-Upload-Token`.
